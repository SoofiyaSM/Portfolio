Projects

Smart Garbage Monitoring System

Academic IoT project

An automated waste management system that detects, classifies and segregates waste, and reports its status in real time.

  1. Sense

    An ultrasonic sensor detects the waste and a moisture sensor helps classify it.

  2. Decide

    An ESP NodeMCU runs the Arduino program that reads the sensors.

  3. Act

    Servo motors segregate the waste automatically.

  4. Report

    The Blynk IoT app shows live monitoring on a phone.
